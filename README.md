# Distelli

Distelli was a Seattle-based DevOps and application-deployment company founded in 2013 by Rahul Singh and backed by Andreessen Horowitz (a16z). It provided a SaaS platform and CLI for building, deploying, and managing applications, later adding a Docker container pipeline and a Kubernetes dashboard.

Puppet acquired Distelli in September 2017. Distelli's VM/CI-CD dashboard became Puppet Pipelines for Applications and its Kubernetes dashboard became Puppet Pipelines for Containers.

**Status: defunct / acquired.** The standalone company, product, and API no longer operate. The `distelli.com` domain is parked and the [Distelli GitHub organization](https://github.com/Distelli) is archived ("no longer supported nor actively maintained").

Backed by: a16z. Retained as a historical portfolio-company record in the API Evangelist network.
